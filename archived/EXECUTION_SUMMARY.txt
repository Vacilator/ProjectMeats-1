================================================================================
DEPLOYMENT STEPS
================================================================================

1. Install Dependencies
   pip install cryptography>=42.0.0

2. Run Migrations
   python manage.py migrate integrations

3. Generate Encryption Key
   python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

4. Set Environment Variables
   OAUTH_ENCRYPTION_KEY=<generated_key>
   MICROSOFT_CLIENT_ID=<azure_app_id>
   MICROSOFT_CLIENT_SECRET=<azure_app_secret>

5. Register Azure AD App
   - Azure Portal → Azure Active Directory → App registrations
   - Create new registration
   - Add redirect URI: https://domain.com/api/v1/integrations/oauth/callback/microsoft/
   - Add permissions: Mail.Send, Mail.ReadWrite, User.Read, offline_access
   - Grant admin consent

6. Test Integration
   - Navigate to Settings → Integrations
   - Click "Connect" on Microsoft Outlook
   - Complete OAuth flow
   - Verify connection status

================================================================================
API ENDPOINTS
================================================================================

GET  /api/v1/integrations/oauth/authorize/?provider=microsoft
     → Returns auth_url for Microsoft OAuth

GET  /api/v1/integrations/oauth/callback/microsoft/?code=X&state=Y
     → Exchanges code for tokens, stores encrypted

GET  /api/v1/integrations/oauth/status/
     → Returns list of connected providers

POST /api/v1/integrations/oauth/disconnect/
     → Disconnects a provider (sets is_active=False)

================================================================================
WORKFLOW NODE USAGE
================================================================================

Configuration Example:
{
  type: 'outlookEmail',
  data: {
    label: 'Send Order Confirmation',
    to: ['{{customer.email}}', 'orders@company.com'],
    cc: ['manager@company.com'],
    subject: 'Order #{{order.number}} Confirmed',
    body: 'Dear {{customer.name}}, your order for ${{order.total}} is confirmed.',
    importance: 'high'
  }
}

Template Variables:
- {{variable}}              → Simple variable
- {{object.property}}       → Nested property
- {{customer.email}}        → Customer email
- {{order.total}}           → Order total
- {{created_at}}            → Timestamp
