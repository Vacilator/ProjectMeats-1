## Why Archive?

1. **Single Source of Truth**: All planning consolidated in Master Plan v3.1
2. **Reduce Confusion**: Clear which documents are authoritative
3. **Preserve History**: Keep historical context without cluttering navigation
4. **Searchable**: Still findable if needed for historical reference
