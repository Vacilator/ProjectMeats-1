# Archived plans

Files in this directory are **archived** and retained for historical context.

They may contain statements that no longer match reality (e.g., “100% complete”).
Do **not** treat these as current requirements.

## Canonical sources of truth
- `/MASTER_PLAN.md` (canonical)
- `/docs/architecture/ARCHITECTURE.md`

## Updating archived documents
Prefer creating a new, current document (or updating `/MASTER_PLAN.md`) rather than editing archived plans.
If an archived plan is referenced by an issue/PR, update the reference to the canonical plan instead.
