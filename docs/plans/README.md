# Plans (Historical)

This directory contains **historical planning documents**.

## Canonical sources of truth
- **Execution status / priorities / “done” definitions:** `/MASTER_PLAN.md` (canonical)
- **Architecture:** `/docs/architecture/ARCHITECTURE.md`
- **Documentation rules:** `/docs/plans/DOCUMENTATION_STANDARDS.md`

## What lives here
- `V3_FINAL_PUSH_PERFECTION.md` is kept here as a **high-level historical blueprint**.
- All other legacy V3.5/V4 planning docs live under `docs/plans/archive/`.
- Any new scoped plan created outside the canonical master plan should use the `YYYY-MM-*` naming rule.

If you are making product or engineering decisions, start with `/MASTER_PLAN.md`.
